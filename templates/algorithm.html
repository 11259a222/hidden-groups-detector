ML Algorithm: Unsupervised Learning

What is K-Means?

No labels! Machine itself finds hidden groups. Like ExoAtlas groups planets, we group customers.

from sklearn.cluster import KMeans
kmeans = KMeans(n_clusters=5)
clusters = kmeans.fit_predict(data)

How it works?

1. Pick 5 random centers
2. Assign each dot to nearest center
3. Move center to middle
4. Repeat till stable → 5 groups found!
